# Population solver (experimental)

This folder documents `cadence.experimental.equilibrium`, a separate experimental
population model of connected patches that repair their shared state and can read
each other's exact prediction errors. For the default brain built with
`Brain.compose`, read [one continuing equilibrium brain](../world-model.md) instead.

```python
from cadence.experimental.equilibrium import Cortex, History, Population
```
