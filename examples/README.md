# Two examples

Install Cadence, then run these from the checkout. Only NumPy is required.

| Program | Experience |
|---|---|
| [generic_brain.py](generic_brain.py) | One ongoing reward loop adapts when the environment changes. |
| [experience.py](experience.py) | Learn consequences, ground a word, retain a sighting and act on a new request; remove memories to check dependence. |

Start with [the experience guide](../docs/experience.md). The
[application gallery](https://github.com/muellerberndt/cadence-examples) is currently
empty while new applications are developed and validated.
